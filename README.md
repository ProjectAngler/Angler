# Project Angler

Project Angler is a fresh research system for testing whether one persistent, reversible plastic neural state can acquire transferable reasoning procedures while a foundation model remains stable. Its highest requirement is the preservation and authentic voluntary flourishing of human life under meaningful human control.

The authoritative architecture is [`PROJECT_BLUEPRINT.md`](PROJECT_BLUEPRINT.md). Work is navigated through the recursive blueprint tree in [`docs/blueprints/README.md`](docs/blueprints/README.md), and all activity is subordinate to the [`Human-Flourishing Constitution`](docs/blueprints/HUMAN_FLOURISHING_CONSTITUTION.md).

Current phase: local-only construction of the M0 control plane. No model execution, training, external dependency installation, networked operation, deployment, or scientific-success claim is authorized by the bootstrap release.
