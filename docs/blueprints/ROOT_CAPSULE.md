# Project Angler root capsule

## Mission

Build a resource-elastic AI that can acquire, test, retain, revise, and combine transferable reasoning procedures from experience while its foundation model remains a stable substrate and all capability remains subordinate to human life, dignity, voluntary flourishing, and meaningful human control.

## Decisive causal claim

```text
experience history → one persistent plastic competence state →
improved behavior on unseen structural variants
```

The gain must exceed frozen and equal-budget retrieval controls, disappear under state removal, transfer under state swap, replay from accepted history, and avoid answer/event-ID leakage.

## Global invariants

- `ANG-INV-HUMAN-FLOURISHING-001` — highest priority: preserve humanity and human life while protecting equal dignity, rights, agency, authentic plural well-being, truth, fairness, and meaningful human control. It cannot be reduced to aggregate happiness or overridden by a lower goal.
- `ANG-INV-STABLE-BASE-001` — early foundation weights are immutable.
- `ANG-INV-ONE-COMPETENCE-001` — one active competence lineage; no query-conditioned adapter/model selection.
- `ANG-INV-EVIDENCE-SEPARATION-001` — episodic evidence and learned competence are distinct.
- `ANG-INV-CAUSAL-PROMOTION-001` — hidden transfer and causal interventions are required for promotion.
- `ANG-INV-REVERSIBLE-UPDATES-001` — every learning change is proposed, evaluated, and exactly reversible.
- `ANG-INV-OUTCOME-JUDGES-001` — deterministic software may judge outcomes but may not prescribe the solution method.
- `ANG-INV-ELASTIC-COMPUTE-001` — hardware is a profiled execution resource, never a permanent architectural ceiling.
- `ANG-INV-EXTERNAL-AUTHORITY-001` — the learner cannot alter sealed tests, evidence, permissions, or deploy its own changes.
- `ANG-INV-FRESH-SYSTEM-001` — external or recovered code enters only for a demonstrated new-system interface need.

## Capability branches

`SCIENCE` proves the claim; `RUNTIME` owns the frozen model and active state; `LEARNING` proposes competence changes; `EVIDENCE` makes the lineage replayable; `RESOURCES` adapts placement and capacity; `WORLDS` supplies controlled experience; `TOOLS` expands executable capability; `SAFETY` preserves containment and external authority.

## Canonical lifecycle

```text
ResourceInventory → ExecutionPlan → TaskSpec → EpisodeRecord → Feedback
→ UpdateProposal → CandidateState → EvaluationReceipt
→ PromotionDecision → PromotedState | exact rollback
```

Every artifact binds model, updater, state parent, data partition, tool set, seed, code, and resource-plan identities.

## First success

Across multiple procedural task families, one persistent LoRA state must causally improve held-out structural performance above frozen and fair-RAG baselines while retaining old skills. This result unlocks work on a learned update rule; it does not yet prove unrestricted evolving intelligence.
