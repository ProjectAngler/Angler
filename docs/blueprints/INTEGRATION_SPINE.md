# Vertical integration spine

The responsibility tree says who owns each design. This spine says how the designs become one runnable system. Every slice crosses branches, produces evidence, and stops at a system-level gate.

All slices and milestones are enclosed by `ANG-GATE-HUMAN-FLOURISHING-001`. A technical or scientific pass cannot override a human-flourishing failure. The learner, updater, tool workshop, curriculum generator, and code-evolution loop cannot approve or waive this gate.

## Control-plane bootstrap

`ANG-CR-0001-CONSTRUCTION-RELEASE-0` is the temporary bridge needed to construct the controls that will later evaluate Slice 00. It authorizes only exact, human-directed, local synthetic schema/scaffold leaves under ADR-0002 and the LOW bootstrap assessment. It forbids model/GPU work, network/dependencies, recovered or real-person data, external effects, and promoted-state mutation. Closing CR0 proves only that its construction package is internally coherent; it does not pass the human-flourishing gate, Slice 00, M0, or a branch delivery gate.

Every milestone also requires a proportionate human-impact assessment, independent human review for high-impact effects, a feasible execution plan, reserved headroom, immutable plan receipt, quality/resource measurements, exact rollback point, and cross-branch contract-version match.

## Advancement rule

Later branches may conduct design work early, but no later capability enters the promoted runtime before its prerequisite slice passes. Failure is interpreted at the earliest incomplete slice; adding unrelated subsystems is not an acceptable substitute.
