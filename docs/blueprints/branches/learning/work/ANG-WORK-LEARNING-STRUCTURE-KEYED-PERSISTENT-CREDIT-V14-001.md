## Accountable outcome

Freeze the complete V13 protected-second representation and add one learned,
persistent, structure-keyed credit memory. A relation code is computed from
the public reference procedure and attempted procedure. Before its outcome is
known, that code may read prior ability state and adjust the frozen V13 outcome
logit. After an objective outcome arrives, a learned writer stores bounded
eligibility/value content under a learned key. Later structurally related but
surface- and family-distinct attempts may benefit.

This is the missing bridge:

```text
frozen Qwen procedure text -> frozen V13 procedure geometry
-> persistent learned eligibility/ability state -> candidate credit
objective outcome -> learned bounded write -> later changed behavior
```

Generic DNC least-used allocation may decide only where a record is stored.
It may not decide its key, value, outcome interpretation, candidate score, or
procedure. No task/family ID, generator metadata, answer, edit label, target
position, deterministic trace comparison, sign arithmetic, query-conditioned
module, per-task adapter, or procedure lookup enters the learner.

Cognee and Moving Origin are not replacements for neural competence. The
fresh state must have an episode serialization that Cognee can durably retain
and rebuild; Moving Origin supplies monotonic acquisition/age coordinates to
the learned reader. The first scientific run uses the same in-process contract
so memory causality can be isolated. Actual Cognee recall and the autonomous
frozen-model runtime are the immediate successor only after this gate passes.

## Frozen representation replication

Before memory training, rehash and load only V13 protected-second weights.
Build a fresh development-only panel of 240 surface instances: exactly six
rows for every combination of eight renderer-pair marginals and five candidate
positions. Cross-cells are diagnostic; pass/fail uses populated marginals.
Every held-out family and transition is balanced. Report each corruption's
pairwise win count and distance margin explicitly.

`STRUCTURE_REPLICATED` requires all of:

- correct retrieval `>=200/240`;
- every renderer-pair marginal and target-position marginal accuracy `>=0.75`;
- paired order win rate `>=0.75` with positive mean margin;
- each of reorder, replacement, omission, and insertion loses to the
  paraphrase in `>=0.75` of rows and has mean distance margin `>=0.05`;
- centered effective rank `>=8`, all 32 dimensions finite/nonzero, mean raw
  off-diagonal cosine `<=0.95`, and fraction above `0.999 <=0.10`;
- direction and semantics lesions retain their V13 causal roles;
- frozen Qwen and every V13 tensor remain byte-identical.

For the lesion clause, direction removal must reduce paired-reorder win rate by
at least `0.10`, and removing step semantics must reduce replication retrieval
accuracy by at least `0.20` versus the full frozen representation.

This is replication on fresh instances of the same synthetic mechanism class,
not arbitrary cross-domain reasoning.

## Persistent-credit training and development protocol

Use the 384 V13 training mechanisms only as generated pretraining experience;
V13 development families remain unseen by the controller. For each public
chronological row, predict before observing its outcome, then write only after
the objective outcome is exposed. The state contains 512 shared learned-key /
learned-value slots, bounded usage/acquisition coordinates, and one monotonic
step. The 288-event development stream therefore requires no eviction. State
size is constant with respect to task count inside the declared capacity.

The V13 representation and base logit are frozen. Train only shared key, query,
value, temporal, and residual networks by backpropagation through chronological
memory writes. Do not replay development events, train on evaluator sidecars,
or directly optimize a development metric. A true-history arm, balanced
within-stream shuffled-outcome arm, zero-state/no-read arm, per-mechanism-reset
arm, and unrelated-state arm begin from byte-identical slow parameters.

The frozen training identity uses exactly 96 AdamW steps, eight mechanisms per
step, and a coprime schedule under which every one of 384 training mechanisms
appears exactly twice. Each step carries one persistent 48-event differentiable
state and predicts before all writes. Learning rate is `3e-4`, betas are
`(0.9,0.999)`, epsilon `1e-8`, weight decay zero, gradient clip `2.0`, float32,
and no autocast or TF32. Qwen is frozen on `cuda:0`; V13 and V14 run on
`cuda:1`. No epoch, step, coefficient, slot, seed, or threshold adjustment is
permitted after the first result begins.

Report chronological loss AUC and balanced accuracy overall, per family, per
transition, and by early/late stage; true-versus-shuffled selection changes;
write/read distributions; state bounds; exact replay reconstruction; matched
and unrelated swaps; early-family retention after all later writes; and
representation/foundation hashes.

`PERSISTENT_PROCEDURAL_CREDIT_SUPPORTED` requires all of:

- true-history balanced accuracy `>=0.70` on the unseen development stream;
- true history beats shuffled outcomes and zero/no-read by `>=0.005` loss AUC
  or `>=0.05` balanced accuracy, and improves at least 9/12 families with at
  least two families in every transition group;
- true history beats per-mechanism reset by `>=0.05` accuracy, establishing
  useful cross-mechanism persistence rather than six-row local fitting;
- zeroing the terminal state removes `>=0.05` accuracy, while replaying the
  identical visible history reconstructs state digest and logits within
  `1e-6`;
- a matched state swap retains at least 90% of its gain, while unrelated or
  key-shuffled state loses `>=0.05` accuracy;
- early-family balanced accuracy after later writes is no more than `0.05`
  below its post-acquisition value without replaying those early events;
- actual true and shuffled histories change candidate order on at least 10%
  of informative rows; global-bias-only changes cannot pass;
- state, gradients, scores, allocation, temporal coordinates, and all read /
  write weights remain finite and inside predeclared bounds;
- all ownership, chronology, no-leakage, corpus-overlap, identity, source-hash,
  final-seal, and frozen-foundation/representation invariants hold.

`STRUCTURE_REPLICATED_NOT_ADAPTIVE` is used if structural replication passes
but persistent credit does not. `PERSISTENT_CREDIT_WITHOUT_STRUCTURE` is a
shortcut/failure classification. Only the full conjunction may open V14 final
and the Cognee/Moving-Origin/Qwen runtime integration successor.
