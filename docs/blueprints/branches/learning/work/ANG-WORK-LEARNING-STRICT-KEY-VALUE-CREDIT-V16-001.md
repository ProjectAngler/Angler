## Outcome and falsifiable claim

Test whether strict separation of learned addressing from outcome value content
turns V15's genuine short-horizon acquisition into precisely bound, durable
ability memory. V15 proved that feedback has usable signal but also proved that
its direct query/temporal decoder paths and mixed writer allowed generic memory
activation and severe read interference. V16 must learn associations; it may
not implement a relation rule, outcome-sign lookup, or procedural solver.

## Strict bottleneck architecture

Create a fresh shared neural core with the same bounded state contract: 512
slots, width 32, usage/acquisition coordinates, monotonic step, predict before
feedback, and generic stable least-unused allocation. Frozen V13 64-D relation
features plus public Moving-Origin temporal coordinates may feed only:

- the learned read query and write key;
- read/write strengths and an outcome-independent erase/retention gate;
- learned address-localization/recency bias.

Objective outcome may feed only a two-token learned value embedding (and a
learned transform of that embedding which receives no structure/time/query/read
input). Stored value content for identical outcome signs is therefore identical
before write-strength scaling. Outcome must not affect key, address, temporal
bias, allocation, or gates.

The score residual must be produced by a bias-free network whose sole input is
the retrieved value. Query, relation, temporal state, key, base logit, usage,
read weights, and any global state statistic may not enter the residual decoder.
An exact zero state or disabled read must produce exactly zero residual. The
foundation/V13 base logit remains frozen and is added only after the residual.

All architecture ownership is mechanically enumerated. Gradient-path tests
must show objective loss reaches query/key/address, outcome-value, and
value-only readout parameters, while no prohibited decoder input/path exists.

## Frozen training and evaluation

Use the exact V15 encoded inputs and counterfactual twin construction: two
acquisition anchors, four probes branched independently from the same
post-anchor state, complete-history derangement, and exact eight-pair state
blocks. Train a fresh V16 core for exactly 96 AdamW updates with the same
learning rate, betas, epsilon, zero weight decay, gradient clip, float32,
no autocast/TF32, per-probe true objective, per-probe ReLU separation against
deranged and detached zero, and paired-twin ReLU ranking with fixed 1/1/1
weights and unchanged margins.

Run the exact V15 development controls and thresholds, including true,
deranged, zero/no-read, post-acquisition reset, equal-budget affine,
outcome-blind value, opposite-twin swap, different-family Hamming-1 state,
occupied-only key/value mismatch, replay, ordering, state bounds, all-family /
transition evidence, six eight-pair blocks, and first-pair retention after seven
later pairs. Add one preregistered same-checkpoint diagnostic required by the
V15 corpus's positional regularity: for probe prediction only, swap the two
relation-class read queries while preserving the target read strength,
temporal features, base logits, state, outcomes, and all stored keys/values.
Mechanically assert that the query changed and every preserved operand remained
exact. A position-only address shortcut is unchanged by this intervention;
learned structural addressing must be harmed by it. Recompute V15
structural/foundation/source identities exactly.

`STRICT_KEY_VALUE_PROCEDURAL_CREDIT_SUPPORTED` requires every frozen V15 gate:

- true streaming probe balanced accuracy `>=0.70`;
- true beats deranged and zero by `>=0.10` accuracy and `>=0.02` NLL;
- paired direction `>=0.75`, paired margin `>=0.20`;
- signed outcome-directed opposite-state reversal `>=0.70` and reversed-label
  causal-gain retention `>=0.80`;
- true beats reset, affine, and outcome-blind controls by `>=0.10` accuracy;
- at least 9/12 families and two families in every transition improve;
- order changes `>=0.25`; zero, unrelated, and occupied-only key/value mismatch
  meet their exact V15 removal thresholds;
- replay is exact within `1e-6`, all state/gradient/weight bounds pass, and the
  worst first-pair retention drop after seven later pairs is `<=0.05`.

Additionally, key/value mismatch must reduce matched accuracy by at least
`0.10` **or** worsen NLL by at least `0.02`, and the value-only outcome-blind
intervention must preserve every address/gate/allocation field while changing
only stored value content. The probe relation-query swap must reduce matched
accuracy by at least `0.10` **or** worsen NLL by at least `0.02`; report both
operands even when the gate fails. This extra removal control prevents a
temporal-position router from being misclassified as structure-key binding; it
does not alter training data, optimization, or the learned mechanism. The other
requirements restate V15 controls rather than tune them.

If fresh-state causal acquisition passes but block retention still fails,
preserve the result and isolate learned episodic context/consolidation as a
later successor. Do not add consolidation, top-k retrieval, eviction, replay
training, or extra capacity to V16; this leaf changes only the bottleneck.

The strict bottleneck retained a small causal value effect but did not learn
structural binding. True streaming BA/NLL was `0.5208/0.7343`, compared with
deranged `0.4792/0.8396` and zero `0.5000/0.8586`. Fresh matched-state BA was

V15's `0.75`, still far above `0.05`).

Therefore V16 supports neither structural key/value credit nor durable
continual memory. It shows that value isolation alone is insufficient: the
training objective does not force the permitted address paths to discover
structural correspondence. Do not add consolidation to this failed address
system. A successor must first isolate a learned, task-generic structural
correspondence objective without evaluator labels, outcomes, answer IDs, or a
hand-coded routing rule.
