## Architecture and borrowed mechanisms

Parse only the literal public `Step N:` framing into raw sentence nodes. The
parser validates a contiguous one-based sequence and supplies directed
`PREVIOUS`, `SELF`, and `NEXT` path incidence. It must never consult role
dictionaries, family keys, structure signatures, generator metadata,
diagnostics, outcomes, seeds, target indices, or evaluator state.

Frozen Qwen embeds every raw public step sentence. Each DNC-selected slot stores
an outcome-blind sidecar containing those detached public step nodes and its
mask, written at the same generic least-used slot as the key/value event. At
read time a small shared neural path encoder adds generic ordinal/endpoint
context and performs exactly two shared-weight bidirectional message-passing
rounds over query and stored traces. First/last/mean/maximum pooled statistics,
their absolute difference, and product feed a bounded bias-free whole-graph
comparator. Its scalar adjusts the ordinary content-address logits before the
unchanged learned top-2 read. Thus the intervention changes the exact failed
V10 boundary—candidate-to-episode addressing—without altering outcome values.

This borrows the causally supported V19 idea of learned paired whole-graph
comparison. V19's learned cross-node attention was empirically equivalent to
uniform attention and did not establish GMN correspondence, so V11 does not
copy learned Q@S attention, add GMN propagation rounds, or make a node-alignment
claim. The comparator is trained fresh because V19's weights consumed a
different graph domain.

The comparator augments a fresh copy of V10's factorized key/value memory with
exact 64-slot DNC least-used allocation. V9's seven outcome-blind pooled-
semantic tensors are the only initialized donor tensors; all trace-graph,
comparator, outcome/value, modulation, scorer, and control tensors start fresh.
Outcome is excluded from parsing, graph encoding, graph sidecars, keys, and
write allocation; it can affect only the factorized stored value.

Deterministic code is limited to strict public framing, tensor shapes, graph
incidence, orchestration, integrity checks, and measurement. It may not score
canonical order, compute distance to a known-success trace, classify failure
mode, select a family procedure, or repair a candidate.
