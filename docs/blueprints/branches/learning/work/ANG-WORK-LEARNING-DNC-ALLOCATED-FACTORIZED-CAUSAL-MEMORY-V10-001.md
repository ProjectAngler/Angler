## Accountable outcome and borrowed mechanism

Borrow the usage-based allocation principle of Differentiable Neural Computers:
write each incoming episode to the least-used available slot, independent of
task, family, semantic content, outcome, answer, or evaluator result. Allocation
is generic memory bookkeeping, never a procedure solver. Learned semantic
content still controls the stored key; V9's multiplicative outcome binding
still controls the value; learned top-2 content addressing still controls reads.

Expand the bounded state from 16x32 to 64x32 so the frozen 48-event development
sequence can retain each event without forced overwrite. State payload remains
only 16,640 float32 bytes. Initial keys/values/usage are zero and slots have no
learned anchors or per-slot logits, so the 16 slots not visited by 48-event
development and the 52 slots not visited by a 12-event training pair cannot
hide untrained slot-specific behavior. Capacity is part of the
allocation/retention test, not evidence that unused capacity alone improves
reasoning.
