Status: specified experimental vertical slice; blocked on V14 component preflight

Active node: `ANG-BP-RUNTIME` / one persistent competence state and bounded

Assurance: LOW; disposable local software tasks with fixed verifiers, frozen
models, bounded file scopes, reversible state, and no deployment

## Purpose and dependency

This is the product-facing continuation of
`ANG-WORK-LEARNING-STRUCTURE-KEYED-PERSISTENT-CREDIT-V14-001`. It may execute
only after the frozen V13 representation loads byte-exactly and the fresh V14
ability-state focused tests pass. V13 remains formally
`DEVELOPMENT_NOT_SUPPORTED`; only its frozen protected representation is an
experimental donor. No V13 OML claim is inherited.

The goal is to test the whole useful loop rather than another disconnected
component:

```text
task + situated Cognee recall
-> attached frozen LLM proposes four natural-language procedure traces
-> frozen V13 geometry + one persistent V14 ability state selects a trace
-> the same frozen LLM acts through the bounded sandbox
-> an immutable task verifier emits objective success/failure
-> journal + Cognee retain the episode
-> V14 state receives one post-outcome credit update
-> later fresh tasks may improve
```

Cognee owns rebuildable semantic candidate recall; Moving Origin owns trusted
time/regime coordinates; the V14 state owns learned procedural competence; the
foundation model owns language and pretrained knowledge. The journal remains
canonical evidence. No component may silently substitute for another.

## Model-agnostic boundary

The attached generator implements only text contracts equivalent to:

```text
propose_procedure_traces(task, recalled_evidence, count=4) -> text traces
execute_with_procedure(task, selected_trace, observations) -> bounded action
```

The first evaluation uses frozen local Qwen3-4B. Angler communicates procedure
guidance as text, so another frozen model may implement the same adapter later.
V13's own frozen Qwen step-embedding sensor remains an internal Angler binding
for this identity; swapping that sensor requires a new compatibility identity.

## Frozen development protocol

Use eight recurring software-procedure mechanisms, each presented twelve times
under unique task text, paths, file contents, and surface forms: stage A learns
four mechanisms, stage B learns four disjoint mechanisms, and stage C
interleaves all eight. Ninety-six acquisition episodes are each seen once.
Thirty-two fresh probe instances are never update inputs; a disjoint final 32
remain sealed.

Each task has a disposable rooted workspace, literal read/write paths, bounded
steps/bytes/time, and an immutable end-state verifier. Verifier source,
expected procedure, diagnostics, family/target IDs, and candidate labels never
enter model prompts or learner tensors before scoring. Cache one identical
four-candidate frozen-model pool per task and reuse it across every arm, with
balanced candidate order and equal recall/token/generation budgets.

Arms are full; frozen V13/static state; Qwen alone; equal-budget unordered fair
Cognee retrieval; zero/reset state; shuffled outcomes; two counterbalanced
unrelated state swaps; and Moving-Origin removed on explicit regime-change
rows. Rebuild Cognee from the canonical journal as a reliability intervention.
No retry, result-informed prompt change, threshold change, or consumed-identity
rerun is permitted.

## Frozen gate

`DURABLE_PROCEDURE_ABILITY_SUPPORTED` requires every condition:

- late 48-episode objective success and terminal fresh-probe success each
  `>=0.65`;
- full probe success is `>=0.15` above Qwen alone, fair Cognee retrieval,
  frozen/static, reset, shuffled, and unrelated/swapped state;
- at least 6/8 mechanisms improve and none regresses by more than `0.10`;
- early-family probe retention after stages B and C loses at most `0.10` from
  its post-stage-A value without ordinary replay;
- zero/reset removes `>=0.15` and at least 75% of the full-over-static gain;
- own state beats swapped state by `>=0.15` in both counterbalanced streams;
- chronological journal reconstruction and process restart reproduce exact
  state digest, scores, selected traces, and deterministic cached outputs;
- incomplete, tampered, incompatible, or tombstoned evidence fails closed;
- keys, addresses, allocation, and usage are exact under outcome derangement
  while learned values differ; shuffled feedback cannot pass;
- full beats Moving-Origin removal by `>=0.10` on preregistered regime-conflict
  rows, otherwise no Moving-Origin causal claim is made;
- same recall, candidate, context, and generation budgets plus exact V13 and
  Qwen hashes hold across arms; all state and effects remain finite/bounded.

A pass proves bounded durable acquisition of recurring software procedures can
improve one frozen attached model. It does not prove arbitrary-model benefit,
unrestricted software repair, cross-domain intelligence, AGI, consciousness,
or deployment readiness.

## Failure, deletion, and rollback

Every neural ability slot binds canonical evidence references. Tombstoning
evidence invalidates dependent slots and rebuilds from remaining journal
entries. Deleting only Cognee's projection is a rebuildable index operation and
must neither erase nor falsely preserve claimed neural competence. Any task
failure restores its parent state atomically while preserving the episode.
Human stop/delete authority is unconditional. Rollback removes only fresh V14
runtime files, disposable workspaces/state, and unpromoted results.
