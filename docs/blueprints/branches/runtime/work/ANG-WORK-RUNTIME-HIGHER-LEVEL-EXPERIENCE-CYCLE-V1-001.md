## Accountable outcome

Assemble one executable closed cognitive cycle in which every component reads
or updates one shared attributed state:

```text
experience -> interpretation -> prediction -> choice -> action
-> consequence -> reflection -> consolidation -> changed state
```

The cycle joins the qualified Qwen3-14B-NVFP4 frozen cortex, a private-research
SEAM-style Qwen3-1.7B structured-experience generator on the RTX 5070, MemRL's
semantic-plus-learned-utility retrieval pattern, Experiential RL's
attempt/feedback/reflection/refinement/consolidation flow, Agent Lightning's
trace/training separation, Cognee reference memory, Moving Origin temporal
state, and Angler's valid canonical consequence/integrity contracts. Existing
small Angler procedure selectors are retained as ablation evidence, not the
primary reasoning substrate.

## Component authority

- Qwen3-14B supplies language, knowledge, imagination, and the public answer.
- The SEAM-style generator supplies bounded executor-conditioned experience;
  it neither answers the task nor judges success.
- Cognee supplies disposable semantic/relational candidate retrieval.
- MemRL-style utility is learned only from attributable past consequences and
  reranks canonical candidates after semantic retrieval.
- Moving Origin supplies acquisition order, age, landmarks, and prospective
  position; it does not assert truth or personhood.
- Objective feedback comes from an external caller/verifier after the exact
  execution receipt. Model confidence and reflection are not outcome truth.
- ERL-style reflection and refinement turn feedback into candidate learning
  material; consolidation remains proposed state until a later promotion gate.
- Agent-Lightning-style spans are append-only trace evidence and carry no
  authority.

Process labels and schemas are deterministic plumbing. No production branch
may inspect a task family, expected answer, hidden label, or verifier internals
to prescribe a solution.

## Integration-first acceptance rule

No component-local score, benchmark, or isolated model output is an acceptance
result. Static/unit checks may only reject broken serialization, leakage, or
unsafe launch before the expensive run; they cannot pass this leaf and must not
be tuned as proxies for system behavior. All functional observations and every
removal comparison execute through the same assembled system path, shared
state, real model adapters, Cognee namespace, Moving Origin, trace ledger, and
consequence/reflection/consolidation sequence. A component that works alone
but fails in the assembled cycle is a system failure.

## Acceptance gate

Pre-live fail-fast checks require:

1. one canonical shared state binds request, memory candidates, temporal
   position, generated experience, prediction, action, receipt, consequence,
   reflection, refinement, consolidation proposal, and next state;
2. semantic retrieval precedes utility reranking, with reset and shuffled-
   consequence removals exposed explicitly;
3. no outcome, verifier diagnostic, or expected answer reaches cortex or
   experience-generation inputs before the receipt;
4. traces are append-only, bounded, canonically hashed, and replayable;
5. failed/clarification execution cannot consolidate or update utility;
6. successful and unsuccessful observed outcomes can both produce graded,
   multidimensional learning material without claiming correctness equals
   intelligence; and
7. every component removal is visible in the shared state and evidence.

The leaf passes only if the assembled live system holds exact model/GPU
identities, Cognee search
and Moving Origin advance, the 1.7B generator emits bounded structured
experience on GPU 1, the 14B cortex emits the public response on GPU 0, one
objective consequence is attached after receipt, reflection/consolidation are
recorded, model inputs contain no hidden expected answer, both GPUs retain
declared headroom, and all new evidence is preserved. A failed task answer may
still be a technical integration PASS if the cycle and attribution are exact.

## Resource and stop bounds

At most one model process per GPU, batch one, 12,288 cortex input tokens,
512 experience-generator input tokens, 256 generated tokens per call, four
Cognee candidates, one initial attempt and one optional refinement, 30 minutes
live wall time, and 2 GiB settled free VRAM per GPU. Stop on wrong GPU, OOM,
NaN/Inf, model drift, malformed schema, network/provider call, trace/canonical
state mismatch, hidden-answer leakage, or undeclared write. Do not silently
replace a failed component with a fake during live evidence.
