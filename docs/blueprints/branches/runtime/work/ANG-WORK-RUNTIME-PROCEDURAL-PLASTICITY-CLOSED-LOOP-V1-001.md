# Procedural plasticity closed loop V1

## Outcome

Prove that Jenny's online procedural state is an active reasoning input rather
than a passive log. An observed outcome or attributable owner correction must
become a bounded, content-addressed procedural case; Cognee may retrieve its
canonical episode reference; the exact case must reach the frozen experience,
controller, and public-cortex boundaries on a related later request. Removing
the case/index must remove that influence without changing model weights.

## Bounded scope

- `src/angler/runtime/procedural_experience.py`
- `src/angler/runtime/cognee_jenny2.py`
- narrowly necessary memory rejoin/projection code in
  `src/angler/runtime/higher_level_autonomy_adapter.py`
- focused procedural, Cognee, and runtime tests
- this leaf and append-only `AGENTS_SYNC.md`

No canonical live episode, Moving-Origin event, base/LoRA byte, permission,
tool effect, emotional label, objective score, or consumed result may change.

## Design constraints

- Semantic retrieval proposes evidence; the frozen model authors applicability,
  procedure choice, and response.
- Deterministic software may validate provenance, content identity, bounds, and
  graph edges, but cannot encode a task solution or route by a hand-written
  topic rule.
- Unevaluated model text is episodic context only and cannot become procedural
  competence.
- Failures and corrections remain usable counterevidence rather than being
  silently discarded.
- The route adds no model call, training pass, adapter swap, or resident VRAM.

## Acceptance

- A focused end-to-end regression shows an evaluated case is projected,
  retrieved by reference, rejoined to canonical bytes, and presented with its
  outcome and Moving-Origin provenance to the later learned decision path.
- A removal arm lacks that procedural evidence while all model-facing fixed
  inputs remain equal.
- A `COMPLETED_UNEVALUATED` episode never receives procedural classification.
- Cognee projection preserves procedural versus episodic epistemic type and any
  exact correction lineage rather than flattening every record to
  `EPISODIC/PROPOSED`.
- Focused and complete runtime tests pass; live state remains unchanged.

## Rollback

Restore only this leaf's source/test edits and restart the Jenny API if source
bytes were activated. Cognee is a disposable projection and may be rebuilt from
unchanged canonical episodes. Canonical episodes and state are not rollback
targets.

## Result

PASS on 2026-09-04. The missing boundary was projection semantics, not another
reasoning model: Cognee had flattened every canonical record to
`EPISODIC/PROPOSED`. Procedural projections now preserve `PROCEDURAL` type,
observed outcome/failure epistemic status, and exact `FEEDBACK_ON` lineage.
Malformed procedural claims fail closed. On startup, evaluated canonical
history is idempotently re-projected so existing learned cases receive the same
typed treatment; unevaluated exchanges remain excluded.

The end-to-end regression proves that an evaluated first case is projected,
retrieved through the reference index, rejoined to immutable canonical bytes,
and supplied to both the learned controller and public cortex on a fresh second
request. The fixed-input removal arm returns no procedural evidence. Startup
bootstrap coverage verifies both evaluated cases are rediscovered from
canonical history.

Validation:

- focused procedural/Cognee/adapter/runtime: 91/91 PASS in 5.141 seconds;
- complete runtime: 480/480 PASS in 53.004 seconds;
- `git diff --check`: PASS;
- live service restart: ready, scheduler and life loop running, zero pending
  operations/projections, and no projection/life error;
- canonical live state remained byte-identical at Moving-Origin ordinal 101,
  state `sha256:6ff2fed4ca98e04996093f468d67fdd1f3fa5e437f3ea184b7255f9fdba1e6f9`.

This demonstrates persistent online state plasticity and active procedural
conditioning without an extra model call or resident VRAM. It does not claim
base/LoRA weight learning, consciousness, emotion, AGI, or broad capability
improvement.
