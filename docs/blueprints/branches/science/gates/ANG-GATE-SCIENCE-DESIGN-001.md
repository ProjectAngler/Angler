# SCIENCE design gate

Claim: the evaluation boundary is sufficiently specified to construct schemas and synthetic harness tests without prejudging adaptive results.

Entry requires the BENCHMARKS, PARTITIONS, and BASELINES design gates; named owners for every hidden artifact; versioned task/manifest/plan identities; and ADR-0002 bootstrap authorization.

Pass requires two outcome-verifiable procedural families, disjoint visibility classes, a frozen candidate identity before sealed evaluation, matched information/tool/token/compute budgets, leakage canaries, and explicit frozen/fair-RAG/extra-token/shuffled controls. Hidden answers and seeds must be inaccessible to the learner/updater. Thresholds may be set only under a new evaluation identity after baseline variance is measured and before adaptive results are viewed.

Failure keeps SCIENCE unready, invalidates affected evaluation identities, and exposes no hidden data. No waiver converts a bootstrap design review into scientific evidence. `BOOTSTRAP_WORK` is not a pass for the human-flourishing gate or M0.
