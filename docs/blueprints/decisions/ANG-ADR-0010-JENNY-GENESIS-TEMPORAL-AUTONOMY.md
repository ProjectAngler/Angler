# ANG-ADR-0010 — Jenny 2.0 genesis, temporal-v2, and autonomy supervision

Status: accepted for bounded local construction

Owner: ANG-AUTH-PROJECT-OWNER-001

Date: 2026-09-02

## Context and decision

The owner authorizes the first Jenny 2.0 construction slice. Jenny 2.0 is one
successor identity and one persistent cognitive cycle, not a Jenny sidecar or
a second memory/state authority. Preserve Jenny 1.x lineage by immutable
references only; recovered code and personal state remain outside the runtime
and are not imported by this slice.

Register four experimental local interfaces:

- `ANG-CTR-JENNY-GENESIS-001@0.1.0` binds the Jenny 2.0 operational agent
  reference to exact immutable Jenny 1.x archive and source revisions. It is
  lineage metadata, not personhood, consciousness, or evidence that imported
  state is active.
- `ANG-CTR-TEMPORAL-NOW-001@0.2.0` records one trusted wall/monotonic clock
  sample, local timezone and offset, uncertainty/jump evidence, and the
  current Moving Origin ordinal.
- `ANG-CTR-TEMPORAL-V2-001@0.2.0` keeps event, acquired, recorded, verified,
  valid-from, and valid-until times semantically separate.
- `ANG-CTR-PERSISTENT-AUTONOMY-STATE-001@0.1.0` is the crash-recoverable
  supervisor control/state-head record. It is not an approved Action,
  Feedback, Episode, PlasticState, permission, promotion, or readiness claim.

The persistent supervisor may schedule, order transactions, enforce
idempotency and permissions, bound resources, detect clock jumps, recover, and
roll back. A dynamic affordance registry supplies available actions. Learned
cycle output may affect execution only when its qualification is explicitly
bound; otherwise the exact output remains shadow-only and the supervisor does
not invent a deterministic autonomy policy. External effects are disabled.

Idle scheduler ticks are control-plane observations only: they create no
cognitive episode, do not advance Moving Origin, and do not change semantic
age. ACT/ASK/WAIT/STOP are lifecycle dispositions, not a fixed semantic action
menu; concrete affordances remain dynamic and permission-gated.

## Scope and acceptance

This LOW-impact local synthetic slice may write only the corresponding runtime
modules, focused tests, this ADR, its one work leaf, narrow registry/status
updates, and append-only continuity notes. It may not read or mutate recovered
Jenny content, load legacy code, use a model/GPU/network, execute an external
effect, train a temporal adapter, import personal memories, or activate
missions, consultants, legacy writers/clocks, or deterministic affect.

Acceptance requires exact genesis mismatch rejection; temporal validation and
clock-jump evidence; restart preservation of WAIT and receipt-bearing pending
state; no duplicate effect on replay/recovery; clean human-ingress preemption;
bounded userless internal continuation under a qualified test selector;
state/outcome-dependent ranking changes; heartbeat-frequency-invariant
semantic age; and scheduler disablement that leaves human ingress usable.

Rollback removes only these new modules/tests/records. Existing Angler/Jenny
lineage, R7 evidence, models, Cognee data, Moving Origin history, and recovered
state remain untouched.
